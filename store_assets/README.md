# Store assets — Google Play (2026 spec)

Ready-to-upload marketing assets for the Play Console listing. All image assets
here meet the current (2026) Play requirements: JPEG or 24-bit PNG, screenshots
between 320–3840 px per side with a max 2:1 ratio, feature graphic exactly
1024×500 with no alpha, ≤8 MB each.

## What's here

| Asset | Files | Spec | Status |
|---|---|---|---|

| **Phone screenshots** | `screenshots/phone/<lang>/01–06_*.png` | 1080×1920 | ✅ 7 languages × 6 |

| **Listing text** (title / short / full) | `../docs/STORE_LISTING.md` | ≤30 / ≤80 / ≤4000 chars | ✅ 7 languages |

Languages: `en, tr, es, de, fr, it, pt`. Each screenshot frames the app rendered
**in that language** under a culturally-adapted headline, in the app's
"Ink & Gold" brand style (Lora serif headline + gold cipher underline + a
floating device card), on a consistent light "paper" canvas across all six.
The app is rendered from a seeded, ENGAGED profile (127 solves, a 23-day
streak, a lively heatmap, 14/24 achievements, real pack progress and a native
mid-length quote on the board) — never a hollow first-run screen. Renders are
captured at 1520×2760 and only ever downscaled onto the canvases, so every
size stays crisp.

Upload order per screen: `01_home → 02_puzzle → 03_stats → 04_ach → 05_packs →
06_premium`.

## Regenerating

The app screens are rendered with the real bundled fonts, then framed by a
Python compositor. Both steps are reproducible:

```sh
# 1) Render the 7-language app screens (writes test/preview/shots/<lang>/*.png).
flutter test test/preview/shots_hires_test.dart --update-goldens --tags preview

# 2) Frame them into localized Play screenshots (writes store_assets/screenshots/…).
python3 tool/make_screenshots.py

# Feature graphics + icons:
python3 tool/generate_icons.py
```

The render harness is tagged `preview` and is **excluded from CI** (it is an
asset generator, not a correctness test) — see `.github/workflows/ci.yml`.
Edit headlines in `tool/make_screenshots.py` (`HEADLINES`).

## Scope notes (what is intentionally not included)

- **Promo video** — not produced here (video authoring is out of scope for the
  asset pipeline). A ready shot-list + 30-second script in all 7 languages is in
  [`VIDEO_SCRIPT.md`](VIDEO_SCRIPT.md); record a screen capture and edit to it.
- **Android XR** — not applicable. Quotecrack is a 2D portrait cryptogram game,
  not an immersive/XR experience, so XR store assets don't apply.
- **Google Play Games on PC** — deferred. It is a separate program requiring
  enrollment and a PC-optimized (landscape, keyboard/mouse) build; the current
  app is portrait-mobile. The brand icon/feature graphic here would carry over
  if you pursue it later.
- **Chromebook** — no dedicated assets needed. The same Android app and phone/
  tablet screenshots serve large-screen/ChromeOS listings.
